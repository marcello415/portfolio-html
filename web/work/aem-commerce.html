AEM, Commerce & SEO

Managing mt.com/rainin in AEM, keeping SAP Commerce Cloud catalogs current, and growing organic search.

Company
Mettler-Toledo Rainin
Role
Web Producer
Years
2016–18
  • 23markets localized
  • North Americastorefronts
  • 3SEO tools in use

The job

A small team ran the Rainin website, online store and email. Web content, product catalogs and translations all had to stay in step across 23 markets.

What I did

  1. Managed web content and digital assets in AEM using component libraries
  2. Kept product content and catalogs current for North American storefronts in SAP Commerce Cloud
  3. Ran localization for 23 markets with Welocalize
  4. Improved SEO with Ahrefs, AccuRanker and Searchmetrics
  5. Built reporting dashboards in Adobe Analytics and Google Analytics
  6. Administered the SharePoint intranet

mt.com/rainin, up close

The Rainin site ran on AEM with a library of reusable components, while the online store ran on SAP Commerce Cloud. Product pages on the website and listings in the store had to say the same thing in every market.

Website (AEM)Built from shared components

Pages used components like carousels, text frames and image blocks inside paragraph containers, so layouts stayed consistent.

Store (SAP Commerce Cloud)Catalogs for North America

Product content and catalog details were kept current so store listings matched the website.

See it working

A step-by-step storyboard of the SmartStand page, using the original copy and image paths, shows how a product page came together in AEM 6 classic UI: components in paragraph systems, a dialog for each one, images from the DAM, the store and 23 markets.

How I did it

  1. Built and updated pages from the component library instead of custom layouts
  2. Kept product content in the store in step with the matching website pages
  3. Sent content to Welocalize and published translations for 23 markets
  4. Fixed on-page SEO issues found in Ahrefs, AccuRanker and Searchmetrics
  5. Built dashboards in Adobe Analytics and Google Analytics to track conversion and engagement

How I checked it

  1. Compared each translated page to the English source before publishing
  2. Checked store listings against the website after catalog updates
  3. Re-checked keyword rankings after on-page fixes

How it helped

With web, catalog and translation work in one set of hands, product pages and store listings stayed consistent across markets.
