AEM Launch Pages

Setting up Apple.com launch pages in Adobe Experience Manager for 100+ locales, and running the weekly navigation release.

Company
Apple (Contract)
Role
Content Manager
Years
2024–25
  • 100+locales per launch

The job

Apple.com launches run on tight, shifting schedules, often several at once. Each launch page had to be built in AEM with the right structure, assets and localized copy for every locale.

What I did

  1. Set up page structure, assets and localized copy in AEM for launches in 100+ locales
  2. Worked with developers to plan page structures and improve content fragment models, components and authoring workflows
  3. Led the weekly Apple.com navigation release and represented the team in weekly partner meetings
  4. Ran UAT in AEM author and stage and wrote up CMS bugs for developers
  5. Built a Quip tool that made QA about 30% faster, and wrote SOPs for onboarding
  6. Trained new team members in California and India

How it helped

Better fragment models and written SOPs made authoring more consistent, and the QA tool gave the team time back on every release.
