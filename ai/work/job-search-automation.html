Job Search Automation

A personal project that runs like a team's request queue: 678 applications taken in, checked, drafted, reviewed and tracked to done with AI skills I built.

Company
Personal project
Role
Builder
Years
2026

The job

Job searching is a lot of admin work. Every application means finding the posting, checking the fit, writing a cover letter, filling out the form and keeping track of where things stand. I wanted the same steps done the same way every time, without losing track of anything.

What I did

  1. Built four Claude skills that work together: job apply, cover letter writing, recruiter outreach and interview prep
  2. Logged 678 applications from 10 job sources on one Asana board, sorted by job type and fit
  3. Set clear rules for what counts as a good fit, like location, job type and level
  4. Matched each application to one of four resumes: web, email, operations or admin
  5. Added a duplicate check so the same job never gets applied to twice
  6. Connected a Google Docs cover letter template so every letter follows my format
  7. Added a checklist that runs before every submit: right resume, right phone and email, right company and job title
  8. Logged each application on an Asana board and filed the confirmation emails in Gmail
  9. Shared a cleaned-up version on GitHub so others can set it up with their own info

Skills I built

  • PersonalJob Apply

    Checks each job against my rules, fills forms with saved answers and logs it in Asana.

    At work: Processing requests and forms the same way every time, with a log anyone can check.

  • PersonalCover Letter Writer

    Copies my Google Docs template and fills it in to match each posting.

    At work: Filling letter, email and document templates quickly without breaking the format.

  • PersonalRecruiter Outreach

    Drafts short follow-up notes for me to review before anything is sent.

    At work: Drafting routine emails and follow-ups for a manager to approve.

  • PersonalInterview Prep

    Turns a job posting and my resume into a practice script and flashcards.

    At work: Building training guides and quick reference sheets for new team members.

How it helped

Every application follows the same steps and gets checked before it goes out. The Asana board shows exactly where each one stands, from applied to interview, and the search has landed 6 interviews so far.
